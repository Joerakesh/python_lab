## Run locally

Python 3.12 is used by the GitHub Actions notebook runner. From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
```

Run an individual program, for example:

```bash
python ex-01-flow-control/ex-01.py
```

Open notebooks with Jupyter:

```bash
jupyter lab
```

## Automated notebook execution

GitHub Actions executes all 13 notebooks when exercise notebooks, dependencies or workflow files change, and can also be started manually from the Actions tab. The run uploads an artifact named **executed-python-lab-notebooks** containing the executed notebooks and outputs. Artifacts are retained for 14 days. See [Actions](https://github.com/Joerakesh/python_lab/actions).

## Notes on results

Where the PDF's output is legible, the exercise README notes the reference result printed in the practical record. This is distinguished from outputs generated by a fresh GitHub Actions execution. Printed lines that are incomplete or visibly garbled in the source PDF are not presented as verified output.
